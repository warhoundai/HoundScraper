# Staged implementation gates

The full accepted product plan is intentionally larger than the initial core release. Stages are published only after actual acceptance evidence exists.

- v0.1: secure HTTP extraction; PostgreSQL jobs/frontiers/leases; page/byte reservations; artifacts and credentials; clients/CLI/MCP/dashboard; audited public repository and hub documentation.
- v0.2: browser/document qualification, broader authenticated workflows, PDF/OCR/Office/EPUB fixture corpus, parser model provisioning, region/language policies and browser pool resource accounting.
- v0.3: provider-specific search and AI acceptance, native Gemini/Vertex adapters, complete field-evidence coverage, product/branding quality benchmarks, S3 storage, optional media transcription and provider spending reservations.
- v0.4: durable autonomous agent planning and cross-source synthesis, shared origin scheduling, monitor pause/update interfaces, SMTP/Slack notifications and optional relevance judging.
- v1.0: end-to-end complete feature matrix, multi-worker fault injection, backup/restore tests, reproducible quality/performance corpus, hardened deployments, and documented compatibility guarantees.

The initial code includes optional browser, parser, model/search and monitoring building blocks. Presence of an adapter is not evidence that an external provider, downloaded model or production topology has been tested. See capabilities.md for current verified scope. No blanket Firecrawl parity, universal target coverage or performance-superiority claim is made.
